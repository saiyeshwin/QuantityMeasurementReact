## Quantity Measurement System

This project is a Quantity Measurement System that performs unit conversions across different measurement categories.  
The application provides an interactive interface for converting units and tracking conversion history in real time.

## Features

### Unit Conversion Logic
- Convert measurements between different units
- Supports categories like Length, Volume, Mass, and Temperature
- Provides accurate real-time conversion results

### Interactive Measurement Cards
- User-friendly conversion interface
- Select "From" and "To" units easily
- Display converted values instantly

### Conversion History
- Maintain a history of previous conversions
- Scrollable history list for quick reference
- Track recent calculation records

### Category Switching
- Navigate between different measurement categories
- Switch between Length, Volume, Mass, Temperature, etc.
- Organized and modular conversion system
